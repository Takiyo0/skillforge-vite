# SkillForge - NestJS Backend

This project is the frontend of SkillForge App, built with Vite.

> This repository is supposed to be built alongside
> the [SkillForge Server](https://github.com/takiyo0/skillforge-nest).

## Requirements

- Node.js LTS + NPM
- [SkillForge Server](https://github.com/takiyo0/skillforge-nest)

## Installation

```bash
$ npm install
```

## Features

<details>

<summary>UI/UX Features</summary>

- [x] Dark/Light Theme
- [x] Markdown Support
- [x] Real-time Updates on Code Execution
- [x] Modal Dialogs
- [x] Code Editor with Syntax Highlighting
- [x] Breadcrumbs for Navigation
- [x] Loading States for better UX

</details>

## Usage

```bash
# development
$ npm run dev

# build
$ npm run build
```
